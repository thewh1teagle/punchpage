Like ngrok, but peer-to-peer.

Share a local web app through a plain browser URL.

No server sits in the middle, there is nothing to sign up for, and the whole session is end-to-end encrypted.

Get started View on GitHub

Install

One command. No account, no daemon, no config file.

Then run punch 3000 to share port 3000 — or punch demo to try it with a sample site.

Why PunchPage

A tunnel that stays between the two ends of the connection.

No server in between

Traffic goes straight from your machine to your visitor's browser over WebRTC.

Nothing to sign up for

No account, no config — install it and share a link.

End-to-end encrypted

The key lives in the URL fragment and never reaches any server.
